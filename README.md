# 🌐 Bootcamp Desarrollo Web Full Stack

Talleres realizados en el bootcamp **Desarrollo Web Full Stack (nivel básico)** del **Ministerio TIC y Talento Tech**, Cali, 2024.

🔗 **Ver los proyectos en vivo:** https://jhoyos-dev.github.io/bootcamp-desarrollo-web/

## 📂 Contenido

| Taller | Tema | Qué se practicó |
|---|---|---|
| [01](taller-01-tabla-html) | Tablas en HTML | Estructura de tablas, imágenes y enlaces |
| [02](taller-02-etiquetas-html) | Etiquetas HTML | Listas, enlaces, multimedia y páginas enlazadas |
| [03](taller-03-formularios-bootstrap) | Formularios | Login, registro y recuperación de contraseña con Bootstrap y validaciones HTML5 |
| [04](taller-04-tabla-css) | Tablas con CSS | Hojas de estilo externas aplicadas a tablas |
| [05](taller-05-transiciones-css) | Transiciones | Efectos `hover`, menús con transiciones y fuentes con `@font-face` |
| [06](taller-06-animaciones-css) | Animaciones | Animaciones con `@keyframes` |
| [07](taller-07-sitio-web-css) | Sitio multipágina | Enciclopedia de dinosaurios con navegación, tablas, transiciones y animaciones |

## 🛠️ Tecnologías

HTML5 · CSS3 · Bootstrap 5

## ▶️ Cómo verlos

- **En línea:** abre el enlace de arriba.
- **En tu computador:** descarga el repositorio (**Code → Download ZIP**) y abre `index.html` en el navegador.

> Los videos de los talleres 02 y 07 no se incluyeron por su tamaño.
